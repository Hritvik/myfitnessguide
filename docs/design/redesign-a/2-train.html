Train: current vs proposed

Train becomes a read-only “what's next”, with a clear hand-off to Claude chat for coaching and logging during the session.

Theme

What changes

Now (live app, main f0a366f)Proposed (refined A, see and confirm)Why
Title is the next workout's name; each prescription card has “Log a set”, and some carry “Reps were as logged” or a gym check (“It's there · It isn't there”).Read-only “what's next”: the session, day, gym and length on top; each card keeps the load, plates, progression chip and cue, and adds last time. No buttons on the cards.Live coaching stays in Claude chat (decided); a card is something to read on the way to the gym.
No path from Train to the chat.A hand-off card: “Train with Claude” opens your chat with the session ready; “Tell Claude afterwards” opens Tell Claude. Sets told to Claude appear in the session as they land.Says where live logging happens instead of pretending the app does it.
An open session lists every set with “Fix…”, a draft set with “Yes, confirm”, and “Save this session as a workout”.The open session is read-only: who logged it and when, the sets, and “Something off? Tell Claude about this session”. A doubtful set shows “question in Waiting”.Fixes and confirms move to Waiting; saving a workout is curation, done in chat or the Catalogue.
A record-only member sees the message that sessions aren't prescribed.The same message, plus Tell Claude for a class or session, and her recent sessions.Record-only members record, never get prescribed.
